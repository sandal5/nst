# Changelog

本文件记录 nst_screenshot skill 的全部版本变更。格式遵循 Keep a Changelog，版本号遵循语义化版本。

## [0.1.0] - 2026-10-28

### Added

- 初版（Gordon 2026-10-28 定版指示 + 同日试点实测）。截图 + OCR 路线的两个适用场景：目录源一次性对象枚举、robots 禁止页面的视觉核验。
- 取页通道定版：WAF 对浏览器 UA 的挑战在本出口无法完成，改用本地 httpx 取页器（默认请求头、每请求新 client、串行、追踪域名短路）经 Playwright route interception 履行请求、本机 Chromium 渲染；指示冲突须在执行报告中明示。
- 展开规则定版：下位机关手风琴初始为空，截图前循环展开至不再出现新按钮；全页截图用 CDP 6,000px 分片 + PIL 拼接，弃用 full_page。
- OCR 与落表闸门定版：3,000px 横带、×2 放大、带间重叠 200px、x 坐标判层级；URL 只作草稿待官方核定，名称三档置信标记、低置信进人工队列，落表行数与来源自报总数对账。
