对 KKJ 目录 3,959 条 URL 做结构分析后的实测分布（按 URL 路径关键词初判，待逐站打开页面后精化）：

| 代码 | 框架类型 | 特征 | KKJ中数量(初判) | 日常采集方式（合规模版） |
|---|---|---|---|---|
| P1 | 入札情報一覧型 | URL/页面含 nyusatsu、bid、procurement；机关官网「入札・契約」分类下的列表页，公告以标题+日期+PDF链接排列 | 约 518（nyusatsu系175＋英语系343） | HTML 列表解析：提取标题/日期/详情・PDF链接；按日期增量 |
| P2 | 調達情報型 | chotatsu/tyotatu 路径，国・独法机关为主（省厅、大学、国立病院等） | 305 | 同 P1；注意同一省厅下多机关共用同一調達ページ，需按机关名过滤 |
| P3 | 公告・公募掲示板型 | kokuji/koukoku/koubo 路径；告示形式，常见于警察、国税、地方局 | 30（URL层面少，实际多藏在P6里） | 列表解析＋PDF 正文抽取（告示号、案件名、締切日） |

| P5 | 契約情報型 | keiyaku 路径；「入札・契約」综合页，公告与结果混排 | 251 | 列表解析时区分 公告中／結果公表 |

| P7 | PDF 直接リンク型 | URL 直接指向 PDF 公告 | 1 | 仅作单件公告样本，不作源头 |

## 按发注机关层级的框架特点（实证）
- **中央省厅・独法（2,160 条）**：多为 P2 調達ページ或 GEPS 体系。大量公告实际上集中在**調達ポータル**一个系统里（公告 PDF 内一贯 안내该入口）——日常采集应「GEPS 集中采集＋各机关調達页补充公募/随意契約公示」。
- **都道府县（62 条）**：KKJ 给的几乎全是**電子調達システム入口**（东京、神奈川等）或旧泛页（大阪旧 pref.osaka.jp 已失效→现行 大阪府電子契約システム enyusatsu.pref.osaka.jp）。每县 1 个系统入口即可覆盖本厅公告；但北海道等是例外：各振興局・教育局・部局各自发公告（碎片化 P6/P1），须按部局建子源头。
- **市区町村（1,737 条）**：分三类——
  a) **共同利用システム型**：参加县级电子调达共同系统（如岛根县电子调达共同利用、神奈川电子入札共同、东京电子自治体共同运营等），1 个入口覆盖数十市町村 → 优先建模，效率最高；
  b) **独自サイト一覧型**：政令市・中核市多有自己的入札情報页（P1）；
  c) **小规模町村 P6 型**：只有首页，公告零散发在「新着情報／お知らせ」里，须用站点新着 RSS/列表＋关键词（入札・公募・プロポーザル）过滤，作为低频源头。

## 采集模版的统一字段（每条公告）
`案件名 / 发注机关（正式名）/ 机关层级 / 都道府县 / 公告日 / 公告种别（一般競争・指名・公募・プロポーザル・随意契約公示等）/ 申请締切 / 入札・開札日 / 原文URL / 附件(PDF等)URL / 来源出处标注 / 采集时刻 / 框架类型(P1-P6) / 源头ID（对应 master_source_list）`
