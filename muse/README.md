# muse/ — 工作日志

本目录保存 Gordon 与助手（Anthony / Muse）在 nst 项目上的对话记录，兼作工作日志。

- 按天两个文件：`YYYY-MM-DD.md` 与同名 `.html`。MD 是正本，给协作者与他们的 agent 读；HTML 由 `scripts/log2html.py` 从 MD 生成，给人看，内容一致。
- 每个文件两部分：**对话记录**（对话体，Gordon 的发言近原文，助手的回复提炼要点与数字）与当日**工作总结**（完成事项、定版决定、关键数字、未决队列）。
- 每天 19:00（Gordon 下班时间）由定时任务汇总当天对话并更新当日文件（先写 MD 再生成 HTML），随仓库一起 commit + push；当天的文件在 19:00 前可能先有一版，19:00 出定版。
- 按仓库统一规则，日志中不出现任何商业公司的名称与其产品名；对话中涉及的此类名称以泛称或〔略〕记。
